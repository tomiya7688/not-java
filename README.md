# Not java ☕❌

**Java の真反対を、ひたすら走るプログラミング言語。**

> Java の逆張りはする。でも、実用性は捨てない。

Not java は、クラス・静的型付け・GC・名前空間など、Java のおなじみの仕組みに別の答えを出そうとする言語プロジェクトです。

現在は **設計・仕様策定段階** です。ここに書かれたコード例は構文の草案であり、実行できる実装が完成していることを意味しません。

## 設計の基本方針

| Java など | Not java |
| --- | --- |
| クラス中心 | クラスなし。変数・関数・メンバーの組み合わせで表現 |
| 型に基づくチェック | 値に型を持たせず、左辺のデータ表現から実行時に演算方法を決める |
| 固定幅の整数・小数 | 整数も小数も必要な桁・バイト数に応じて自動伸縮。終わらない除算は有限長で打ち切る |
| 文字列表現 | UTF-8 のバイト列を基本とする |
| GC による自動回収 | `free` による手動解放 |
| 変数の宣言 | 使うと生成。未設定なら `null` |
| 参照を共有するオブジェクト代入 | データをコピー |
| `import` / `package` / `namespace` | 相対ファイルパスを `.` でつないで参照 |
| 固定名 `main` など | エントリーポイントをコンパイル時に指定可能。省略時はソースの先頭から順に実行 |

## こんな言語にしたい（構文は仮）

```text
fn hello() {
    print(`Hello, World!`)
}

a = hello
a()
free(a)

// a は解放され、再び参照すると null
print(a)
```

文字列は **UTF-8** のバイト列として格納し、整数も小数も必要なサイズまで自動で拡大・縮小します。数値と文字列を勝手に変換しないのも重要な特徴です。

```text
5 + `5`  // 数値方式の加算
`5` + 5  // 文字列方式の加算。数値5を文字「5」にはしない
```

## 文字列はUTF-8、数値は自動で伸縮

```text
`A`   // UTF-8: 41 （1バイト）
`あ`  // UTF-8: E3 81 82 （3バイト）
255   // 数値データに必要な最小バイト数
256   // 必要なら自動で1バイト拡張
```

小数も必要なら桁数を増やします。ただし**小数計算中に3回メモリを拡張しても結果が確定しない場合は、1回目の拡張時点の精度まで切り捨て**ます。循環の検出自体は必須としません。整数の自動拡張には、この3回制限を適用しません。

```text
0.1 + 0.2  // 計算完了なら 0.3
1 / 8      // 必要な拡張内で完了すれば 0.125
1 / 3      // 3回拡張しても終わらなければ1回目まで切り捨て
1 / 7      // 同上
```

※ 1回の拡張と小数の桁数との対応は、数値の内部表現が決まってから定義します。長い**有限小数**も3回の拡張で完了しなければ打ち切られる可能性があります。
固定小数点のような抽象化は**標準ライブラリで提供する方針**です。ただし、Not javaには型宣言やクラスがないので、まず関数・変数・構造的な値を組み合わせて**型に相当する仕組みそのもの**をライブラリ側で作ります。言語本体には固定小数点の組み込み型を増やしません。

```text
// 概念例（構文は仮）：123.45を整数12345と倍率100で表す
amount = 12345
scale = 100
price = amount, scale
```

このような整数ベースの計算には、小数演算の「3回拡張」制限は直接かかりません。整数データ自体は必要なだけ自動伸縮します。

実際の標準ライブラリでは、生成・加算・表示などの関数も用意する想定です（具体的なAPIは未決定）。なお `==` は生バイト比較なので、`123.45` を異なる倍率で表現した場合の数値比較は、ライブラリ関数で処理する必要があります。

## 条件分岐にも型はいらない

`If(条件) { ... }` を採用します。Boolean型を要求せず、条件のデータが**全バイト0なら偽、それ以外なら真**。0バイトの `null` も偽です。

```text
A = 10
B = 10
If(A == B) {
    print(`Equal`)  // 比較結果1 → 真
}
If(A - B) {
    print(`Different`)  // 差は0 → 偽なので実行しない
}
```

比較演算 `==` は**値データのバイト数と各バイトをそのまま比較**します。すべて一致なら数値 `1`、そうでなければ `0` を返し、型や格納方式の名前で一致・不一致を判定しません。専用の真偽値型もありません。

```text
65 == `A`   // 1（数値65を0x41の1バイトで表す場合、UTF-8のAも0x41）
15 == `15`  // 0（バイト数・内容が違う）
0 == null   // 0（1バイトと0バイト）
null == null // 1（どちらも空のバイト列）
```

※ 文字列の基本文字コードはUTF-8で確定。小数の「3回拡張して未完了なら1回目まで切り捨て」も方針決定済みです。数値の内部表現・`Else` の詳細な文法は今後検討します。

## エントリーポイント

特別な名前の `main` 関数は不要。エントリーポイントを指定しない場合、指定されたソースファイルの内容を**上から順番に実行**します。任意の関数を入口にしたい場合は、コンパイル時に指定できます（CLIの具体的な構文は未決定）。

```text
// エントリーポイントの指定なし（構文は仮）
print(`First`)
print(`Second`)
// First、Second の順に出力
```

トップレベルでは、関数を定義してから変数へコピーし、そのまま呼び出すこともできます。

```text
// 概念例：関数定義構文は仮。呼び出しは A() で十分
B() {
    print(`Hello`)
}
A = B
A()
free(A)
```

`B` は元の関数、`A` は関数をコピーした変数です。指定がない場合、上から順に定義・代入・実行・解放を進めます。`B` の元の関数定義はプログラム終了まで存在します。

`B() { ... }` は後続の `{ ... }` によって関数定義と識別でき、`A()` は関数呼び出しとして解釈できます。専用の `Execute` キーワードは不要な設計です。呼び出し対象が関数として実行できるかは実行時に確認します。
