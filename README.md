# Not java ☕❌

**Java の真反対を、ひたすら走るプログラミング言語。**

> Java の逆張りはする。でも、実用性は捨てない。

Not java は、クラス・静的型付け・GC・名前空間など、Java のおなじみの仕組みに別の答えを出そうとする言語プロジェクトです。

現在は **設計・仕様策定段階** です。ここに書かれたコード例は構文の草案であり、実行できる実装が完成していることを意味しません。

## 設計の基本方針

| Java など | Not java |
| --- | --- |
| クラス中心 | クラスなし。変数・関数・メンバーの組み合わせで表現 |
| 型に基づくチェック | 値に型を持たせず、左辺のデータ表現から実行時に演算方法を決める |
| 固定幅の基本整数 | 必要なバイト数に応じて自動で拡大・縮小 |
| GC による自動回収 | `free` による手動解放 |
| 変数の宣言 | 使うと生成。未設定なら `null` |
| 参照を共有するオブジェクト代入 | データをコピー |
| `import` / `package` / `namespace` | 相対ファイルパスを `.` でつないで参照 |
| 固定名 `main` など | エントリーポイントはコンパイル時に指定 |

## こんな言語にしたい（構文は仮）

```text
fn hello() {
    print(`Hello, World!`)
}

a = hello
a()
free(a)

// a は解放され、再び参照すると null
print(a)
```

数値と文字列を勝手に変換しないのも重要な特徴です。

```text
5 + `5`  // 数値方式の加算
`5` + 5  // 文字列方式の加算。数値5を文字「5」にはしない
```
